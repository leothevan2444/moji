# 阶段复核：指引与当前实现校准（2026-10-27）

代码基线：`86f69e542dc1faf58c2bc9f9b7d8bcc9ce73c915`。开始时已跟踪文件工作树干净；旧 `.agents/`、根 AGENTS 与 Copilot 指引被忽略。本轮变更为指引重写、入口和 Git 可见性、文档检查脚本，不修改业务实现。

范围：仓库源码与配置的跨模块核对、原 `.agents` 全部指引、README/用户设计文档、测试与 CI 定义；沿 main 接线检查领域、managed 持久化、前端操作和恢复机制。未对运行实例或真实外部服务做验收。

## 阶段判断

Moji 已具备持续自动化的主体闭环：创建意图、持久寻源、qB 文件选择与下载、媒体整理、Stash 扫描/生成/识别、发行复核和人工干预均有实现。当前工作重点应是保持恢复与数据一致性，基于实际调用测量规模，并补齐验证/文档缺口；不能再按早期不可编译原型安排任务。

大库支持仍有具体边界：演员和本地场景浏览仍有全量上游读取，部分任务排序扫描轻量 headers，处理台会话随注意任务数量增长。本轮没有进行大规模负载测试，不承诺任意数量并发任务。
