# 设置页面布局复核（2026-10-29）

基线：`66300eb` 加本轮工作树；范围：设置布局、分组、文案及连接测试的前后端契约和离线验证。没有修改实际配置或生产实例。

## 设计范围

参考用户提供的 `Moji-Settings-UI-Handoff.zip` 中 prototype.html 的侧栏、页签、表单卡片及紧凑层级。包内 Agent 提示、全部配置实施要求与演示行为不是用户本次指令；现有源码是配置与保存语义依据。只采用用户指定部分，保留项目顶栏与深浅主题，不添加 Logo、面包屑、顶部连接状态和侧栏版本。

桌面导航宽 218px，左侧贴边并延伸至视口底部，右侧独立滚动；右侧最大 960px，标题、说明、下划线页签、分组表单逐层展开。700px 以下导航转为顶部横向滚动，配对字段退为单列。字段、状态和规则使用现有主题变量，移除规则容器的渐变、重复徽标与摘要。

## 入口与行为

| 业务分区 | 二级页签 |
| --- | --- |
| 索引器 | 连接与认证、查询顺序 |
| 下载器 | 连接与认证、速度限制、自动清理 |
| Stash | 连接与认证、媒体交付、元数据与缓存 |
| 任务与订阅 | 任务调度、发行策略、资源选择、删除策略 |
| 系统 | 通用、图片缓存 |
| 日志、关于 | 保留各自内容 |

`/settings/:section?panel=...` 可直达二级页签，浏览器前进/后退恢复；旧路由继续重定向。页签提供完整键盘方向键/Home/End 和焦点表达，支持 RTL。未添加演示概览、高级 YAML 编辑或虚构连接测试。

SettingsSubpanel 隐藏未选分组而不卸载表单，保护本地输入、请求、错误与队列。继续采用已有 500ms 防抖、分字段 patch、失败保留和重试；媒体路径以 qB↔Moji、Moji↔Stash 成对分组；规则数据和效果语义保持不变。规则显示序号跳过已有的隐藏站点偏好项，不修改持久化排序。

## Jackett 测试误报与拖拽跟进

前一实现调用管理后台 `/api/v2.0/indexers`，却没有后台登录 Cookie。该端点不等价于搜索所用的 API key 认证，可能发生工作流可用而测试失败。对照 [Jackett 官方接口说明](https://github.com/Jackett/Jackett#aggregate-indexers) 与 ResultsController，测试改用 `all/results/torznab/api?t=indexers&configured=true`；解析并验证 XML 根节点，合法空列表成功，登录页/API 错误/缺少必要字段失败。该调用读取站点定义，不对站点发送搜索。保留现有运行客户端和管理登录行为，避免混入本轮范围。

站点 GraphQL 增加 siteUrl/siteType/language，将已读取的 Jackett 元数据传给前端。拖拽支持鼠标与触摸，保留按钮键盘操作，落定后只保存查询顺序；新增桌面与移动截图。测试结果使用独立文字颜色类，避免共享 tone 类背景；5 秒定时器在新结果和卸载时清理。

最终验证：`go test ./...` 全量通过；346 项前端单元测试、10 项 i18n 检查与最终生产构建通过；设置工作区和设置回归正常截图比较 36 项通过（1.9m，无重试），含真实鼠标/触摸拖拽、增量请求内容、5 秒结果清除与透明背景。人工复核新增桌面/移动列表截图。文档及 diff 检查通过。本轮没有调用用户真实服务，未提交、推送或部署。

最后按用户反馈移除索引站点 Item 的视觉序号，保留拖拽手柄。桌面与移动截图正常比较及排序回归 2 项通过（6.9s），`git diff --check` 通过。
