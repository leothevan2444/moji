# 索引执行统一记录复核

日期：2026-11-08。基线：694f0ec 上的本轮工作树。范围：任务等待资源、执行历史、站点最近 10 次状态、主页搜索统计、Jackett 自动目录加载及实际运行库手动处理。

## 最终模型

runtime v7 新建 `indexer_executions`；一份 JSON 正文保存执行结果和上下文，SQLite 生成列派生站点、操作、时间、结果和统计资格并建立索引。去掉独立近期快照与分钟聚合存储。历史、图标和统计从同表读取；区间统计与记录数共用读事务。实际执行关联 ID 用于合并调用去重，缓存和未执行调用可查阅但不计实际执行，取消不影响成功率或图标。搜索耗时不包括后续候选处理或取种。平均耗时仅对已有可靠耗时的搜索样本求均值；缺失耗时不计入分母，无样本或均值为零显示 "-"，不展示缺失耗时提示，也不估算旧报告耗时。

完整保留近 14 天全部记录，无全局 4096 条上限；每个仍配置站点额外保护最近 10 次有效执行，即使已超过 14 天。移除站点仅失去额外保护。Jackett 目录未确认时保守保护其既有站点最近记录，不阻止其他过期记录清理。历史可查看受保护的旧记录，区间统计仍按所选时间计算。

schema v7 仅创建空表和索引，产品代码无旧结构转换或兼容读取。

自动寻源的站点错误安排下次资源检查，不再作为任务异常；明确选定的资源保留冻结来源并按原意图重试。存储、Stash 查询或无效请求仍保留可处理的任务错误。主页提供 24h/72h/两周统计，启用站点始终显示纯数字。记录窗口直接显示上下文、支持筛选和搜索，图标按最近执行结果显示正红或黄色。

Jackett 目录由应用生命周期内的后台 worker 在启动后自动加载，配置启用且连接完整时才请求；配置变更唤醒、周期检查复用现有缓存和退避，请求随退出取消。刷新失败保留同一连接最近确认的目录，不跨账号复用；不会阻塞 HTTP 启动或配置通知。移除不再使用的主页总数完整性字段和限定数量文案。
