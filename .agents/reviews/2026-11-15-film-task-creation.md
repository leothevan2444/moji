# 任务先确认 StashBox 影片

## 已采用的契约

所有生产任务由 taskflow 接收，先确定 StashBox endpoint、scene ID 和影片快照，再进入执行。来源和影片 ID 是身份，完整番号额外防重；仅统一番号大小写和首尾空白，保留数字前缀、字母后缀和零填充。

用户指定资源先推荐影片，允许关键词搜索、切换已配置来源，并展示服务器重新读取的影片。确认摘要绑定展示的资料，创建时再次校验；指定资源另需明确确认。正式接收前不创建任务或提交 qB。接收后以 DOWNLOADING/PENDING 保存影片和资源，后台取得原始种子或磁力后提交下载；失败等待用户重试同一资源，不回到自动寻源。旧的番号/链接直接创建 GraphQL 入口已删除。

自动寻源沿用 SOURCING → DOWNLOADING → 入库流程。演员选片和订阅观测已有的完整服务器快照可以直接复用；持久化复核记录不保存这个临时证明，后续操作重新读取来源。网页不能提交影片快照来绕过核验。

番号提取只存在于 taskflow 的资源推荐模块，沿用旧规则。资源和文件匹配只比较已知目标的完整番号，不猜测其他番号。无分隔的字母后缀可能属于另一部影片，不能自动作为分段；有明确分隔的分段仍可自动排序，身份或顺序不明时要求人工选文件。Stash 入库结果必须含任务指定的 endpoint + scene ID；同号不能代替来源关联。
