# 资源选择引擎重构验收

日期：2026-11-21；范围：本轮工作区，不表示生产服务已更新。设计见[资源选择引擎](../plans/resource-selection.md)，用户设置见[资源选择](../../docs/resource-selection.md)。

## 采用与交付

- 新增无 I/O 的 resourceselection 内核；默认原版、无硬字幕优先，画质中立，偏好可排序，高级规则统一条件表单。
- 移除旧 LOCK/AVOID、快排和文件阶段设置；严格拒绝旧配置，不新增自动配置迁移。
- 自动寻源跨站保留候选，达到首选后早停；无首选时选择已验证回退。预算不足时，未检查候选不会冒充推荐。
- 人工指定仍保留原资源和附件，但不能绕过目标番号、哈希及有效 magnet 校验；人工换源生成新报告，不展示旧自动决定。
- 决定包含版本、策略、证据与覆盖范围，原子保存于核心检查点；预览使用原搜索 worker 的持久作业，可取消、刷新恢复，重启中断。
- GraphQL、生成绑定、设置、发现页、任务选源、详情、i18n 和用户文档同步更新。大小条件界面输入 GiB，配置/API 保存整数 bytes。

- `GOCACHE=/tmp/moji-go-cache go test ./...`：通过；覆盖 core v9→v10 的旧任务保留及报告大小约束。真实站点测试保持默认跳过。
- 完整 race：resourceselection、taskruntime、torrentsearch 通过；最终又对本轮选择、当前来源、预算、报告、预览取消/重启场景跑定向 race，通过。
- `npm --prefix web test`：82 个文件、515 个用例通过。
- Web build、i18n:check、GraphQL 生成、文档检查和 diff whitespace 检查通过。
- Playwright 使用仓库固定 v1.61.1-noble 容器：资源选择 14 项、已有资源搜索 24 项，共 38 项相关场景通过。包括中英、深浅色、桌面/移动、RTL 长标题、预览分页、取消、影片确认、检查刷新恢复、任务推荐和持久报告。新增和受影响截图已复核；没有更新下载器等无关基线。
- 本机单次基准：1,000 候选 ×32 条规则 ×8 条件，约 462 ms、4.2 MB 分配；这是离线纯决策样本，不是站点响应或生产吞吐保证。
- 已对 44 个本轮未涉及的原有修改文件做初始 blob hash 对照，未发现被覆盖。共享生成文件、locale、任务详情及测试夹具按本轮需求合并。

## 本地配置与运行边界

本地配置先预演，再备份并手动转换；保留 19 条 EXCLUDE 和一条 PREFER，将一条 LOCK 转为最高自定义 PREFER，其他配置语义经完整 YAML 对照保持一致。旧发布时间、大小、单视频排序不迁入新模型。

原始私有备份为 `backups/config-resource-selection-20261121T080218Z.yaml`，文件权限 0600；备份和 config.yaml 均由 Git 忽略。转换后通过 `go run ./cmd/moji-config -config config.yaml` 校验。

没有部署、重启服务、执行真实站点验收、创建提交或推送。数据库迁移将在新版服务正常启动流程中应用；本轮验证使用临时数据库和 fake/httptest。
