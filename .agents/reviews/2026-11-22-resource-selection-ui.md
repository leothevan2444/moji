# 资源选择设置卡片与编辑窗口

日期：2026-11-22；用户路径：进入任务与订阅的资源选择分区，查看默认组/检查范围、规则库、规则组三张卡片，点击名称或组摘要打开独立编辑窗口；编辑沿用串行自动保存，关闭后草稿保留，可重开继续，错误可重试。

## 实现

复用 SettingsCard/SettingsGroup、settings-field/SettingsSaveStatus 和 Drawer/useModalFocus/Portal。规则卡片只显示名称，网格一行可显示多项；组卡片尺寸更大，显示默认标记、必须/排除/层级数量和前三个层级名称。主列表不内嵌表单。

ResourceSelectionEditor 拥有选中的对象 ID 和卡片布局，ResourceRuleEditor 与 ResourceRuleGroupEditor 分别负责编辑内容，使用现有父级自动保存草稿。只在主界面或编辑窗口内显示一份保存状态，失败后不丢内容。共享规则删除保护和默认组删除后的接续选择保留。新增规则/组直接打开对应窗口；Escape/关闭/遮罩沿用共享模态行为，关闭恢复触发卡片焦点；删除后聚焦添加按钮。切换到其他设置分区会关闭 Portal，保留父级草稿。

样式使用既有主题变量和 SCSS token，保持其他设置页的卡片标题、字段和按钮层次；规则条件数量继续不限。没有更改后端、GraphQL、规则语义、配置格式或数据 schema。
