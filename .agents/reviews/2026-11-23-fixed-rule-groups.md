# 规则组固定组合与兜底开关

日期：2026-11-23。状态：已实现、验证并更新本机运行实例。用户要求前置准入/排除固定 ANY、优先层级固定 ALL，删除相关组合设置并将兜底独立为布尔开关。规则内多条件固定 OR 沿用[前一轮模型](2026-11-22-any-condition-rules.md)。当前契约见[设计](../plans/resource-selection.md)和[用户指引](../../docs/resource-selection.md)。

## 契约

策略与解析版本 5；Group 删除 requireMode/excludeMode，新增 fallback；Tier 删除 mode/matchAll。前置无准入引用表示不限、无排除引用表示不排除，命中任一排除优先于准入。真实层级需要全部引用成立，局部取反仍保留，UNKNOWN 不取反为已知。

允许 0–16 个真实层级，空条件层级非法。fallback 开启后，已通过前置且不能命中真实层级的资源以 len(tiers) 排序，原因 FALLBACK_ALLOWED，无虚构层级名，不触发第一层早停。高层或前置必要未知仍需检查。关闭时只能采用真实层级；若已确定全部层级不能命中，即便前置未知也直接拒绝。零层级且关闭开关意味着不自动选源；界面明确说明，允许先建空规则库的组再开启仅过滤兜底。

编辑界面前置仅标签和添加选择，层级仅名称与标签引用；复用 SettingsSwitch/FieldLabel 提供“允许兜底选择”及说明。所有真实层级都可删除/排序，组卡片显示兜底状态。GraphQL、YAML、设置 patch、解释与生成产物同步，无生产自动迁移和数据库 schema 改动。

## 本机转换预演

当前配置包含 8 条规则、1 个组，前置 ANY、真实层级仅一条规则、末尾存在兜底。转换保留规则定义与真实层级，兜底转 true；固定组合未改变当前配置含义。20,000 组旧/新求值对照资格、优先层级和未知状态无差异，其他配置语义不变；新 loader 校验候选后才可备份、原子应用。若旧配置存在多条 ALL 准入/排除或 ANY 层级，按用户本轮指定改为固定语义，转换记录显式统计这些语义变化。
