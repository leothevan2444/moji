# 下载器管理

Moji 在主页提供下载器统计，通过“查看种子列表”打开种子管理弹窗，在 `/settings/downloader` 配置清理和限速，qB 继续负责 BT 协议和文件下载。
支持 qB 5 的 start/stop API；旧版返回 404 时回退到 resume/pause。
会话过期或 qB 重启后自动重新登录；初次登录失败不会阻止 Moji 启动。
仅在明确收到 403 时重新认证并重试，不重试结果不明的超时写操作。

- 每 3 秒独立监控一次，包括已完成 Moji 任务对应的种子；主页、列表和任务详情每 3 秒读取后台快照。任务状态复用同一份 qB 列表更新，不等待入库处理周期。
- 种子列表以 qB 最近成功同步时仍存在的种子为主，按 Hash 匹配关联 Moji 任务；未关联的 qB 种子仍显示，找不到 qB 种子的 Moji 任务不补入列表。筛选、数量和分页均遵循这一范围。任务详情继续保留种子丢失与清理记录。
- 桌面使用独立种子列和关联任务列的表格；手机使用紧凑列表。详细信息按需展开，启停之外的操作集中到“更多操作”，移除操作仍需确认。
- 显示上传/下载速度、分享率、累计做种时间、传输量、ETA、连接的 seeds/peers、可用副本数、分类、标签、路径及关联任务。
- 支持启动、暂停、重新校验、重新汇报 Tracker、全局速度限制和种子移除。
- 移除、删除文件和重新校验需要在页面中确认；命令提交后以 qB 的下一次观测为准。
- 下载中的种子丢失或出现 error/missingFiles 时，任务进入受阻状态；恢复后自动继续。其他入库阶段仍显示种子状态，不会因此回退已完成的入库工作。已完成任务的种子丢失和源文件缺失显示为中性信息，不计入异常。
- qB 连接失败不会视为全部种子丢失；显示最近成功快照和过期提示，停用操作按钮。

## 自动清理

默认关闭。触发条件包括分享率、累计做种小时数、任一条件达到、全部条件达到，以及入库后立刻清理。
选择立刻清理时，在全部关联任务完成后的下一次同步执行，不等待分享率或做种时长。
只对已下载完成、所有关联 Moji 任务均已完成的种子执行；不会自动删除未关联的 qB 种子。
校验和文件移动过程中不执行清理；立刻清理模式可以移除已完成移动入库、源文件已缺失的旧种子。

首次配置默认选中“同时删除下载文件”，但只有启用自动清理后才会执行。已有明确保存的选择保持不变。
选择删除文件时，必须确认任务使用 copy 或 move 入库且已经完成，
本机可访问的下载源目录和入库目录相互独立，且 qB 中没有其他种子引用重叠内容路径。
检查失败时保留种子和文件，等待人工处理。未完成入库的关联种子禁止手动移除。
这套策略由 Moji 执行，不会改写 qB 自身已有的分享限制或清理设置；应避免在 qB 中另行设置会提前删种的策略。

策略和最近一次观测保存在运行数据库的 `downloader_state` 表中。删除前先保存意图，
随后确认 qB 中实际消失，再记录 POLICY/MANUAL 来源和确认时间。
未完成确认的命令保留 PENDING 来源。意外消失显示 missing，仍保留最后观测的分享率和做种时间。
本机重启不会丢失这些记录；不保存每次轮询的历史时间序列。

## 存储指标的含义

剩余空间来自 qB `/sync/maindata` 的 `free_space_on_disk`，表示 qB 默认下载盘的空间，
不是 Moji 容器所在磁盘，也不覆盖所有自定义下载盘。
“种子已完成数据量”和“待下载数据量”为 qB 报告值之和。预分配、硬链接、交叉做种、
未选择的文件及磁盘上其他文件会影响实际占用，因此不能据此计算准确的磁盘占用率。
接口未报告空间时显示未知。
