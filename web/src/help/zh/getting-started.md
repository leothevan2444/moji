# 开始使用

Moji 是 Stash 的伴随服务：发现发行内容、把下载提交给 qBittorrent、将已完成内容交付到 Stash 媒体库，并通知 Stash 扫描。媒体的编目和展示仍由 Stash 负责。

> Moji 不会替你安装或配置 Stash、Jackett、qBittorrent 或 StashBox。

## 使用前准备

下载与入库需要正在运行的 Stash 和 qBittorrent。在 Stash 中配置至少一个 StashBox 端点，用于确认任务对应的影片；端点要求鉴权时填写 API key。寻源可使用 Moji 内置站点或外部 Jackett，至少启用一个可用站点。Jackett 是可选依赖。

Moji 服务端必须能访问所用的服务和站点。使用文件交付时，Moji 还必须能读取下载目录并写入媒体库目录。

## 首次配置

1. 在 **设置 > 索引器** 下载规则库并添加内置站点，或配置并启用外部 Jackett；在 **设置 > 下载器** 配置 qBittorrent，在 **设置 > Stash** 配置 Stash 的 URL 和凭据；修改会自动保存。
2. 返回 **主页**。只有最近一次探测成功才表示服务“就绪”；“已配置”不等于连接正常。
3. 打开 **设置 > Stash**，配置 qB 下载、Moji 下载、Moji 媒体库及 Stash 媒体库四个根目录，并选择复制或移动。
4. 打开 **设置 > 任务与订阅**。选择任务推进频率，并检查发行策略与资源选择规则。StashBox 优先级位于 **设置 > Stash**。
5. 在 **发现** 中搜索，或从 **演员** 详情加入影片。随后在 **任务** 中跟踪，直到文件交付及 Stash 扫描、生成、识别和校验完成。

## 安全完成首次任务

先搜索并确认一部 StashBox 影片。确认路径前，文件交付动作保持为 **复制**。检查 qBittorrent 内容路径确实位于 qB 下载根目录下，最终扫描路径确实位于 Stash 媒体库内。任务完成后先在 Stash 中验证影片，再扩大订阅自动化范围。
