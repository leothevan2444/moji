# 产品简介

Moji 是 Stash 的自托管伴随服务，协调影片发现、资源选择、qBittorrent 下载、文件交付，以及 Stash 扫描、生成、识别和结果校验。

## 数据与分工

Stash 保存演员、订阅标记和媒体库；StashBox 提供影片资料。Moji 保存检查安排、发行决定、下载任务与恢复状态。qBittorrent 负责 BT 传输；内置索引器和可选 Jackett 提供资源搜索。

## 主要流程

1. 在 **发现** 或演员详情找到并确认 StashBox 影片。
2. 创建自动寻找资源的任务，或确认影片后使用指定资源。
3. 由 Moji 验证资源并跟踪 qBittorrent 下载；文件不确定时等待人工选择。
4. 将单文件或合并后的影片复制或移动到媒体库。
5. 由 Stash 扫描、生成和识别，Moji 核对影片资料及精确的 StashBox 关联后完成任务。

下载或扫描完成都不代表整项任务已完成。受阻时保留原因，可以处理后从相应步骤重试。
