# 任务与入库

任务是 Moji 针对单个发行内容保存的持久记录，包含所选种子、qBittorrent 状态、交付路径、Stash 扫描任务、错误和时间。删除任务时执行 **设置 > 系统** 中的删除策略。

## 任务生命周期

1. **待选种**：Moji 搜索 Jackett 并排列可下载候选；手动选择 Jackett 结果时跳过自动选择。
2. **下载中**：种子已提交给 qBittorrent，Moji 定时同步名称、进度、状态和内容路径。
3. **待入库**：下载完成，等待计算入库路径。
4. **搬运中**：Moji 过滤和去重文件，将分段正片依次无损合并，单文件保留原格式交付为 `番号/番号.原扩展名`，多分段合并为 `番号/番号.mkv`；启用保留的字幕与正片对应命名。
5. **Stash 入库**：Moji 依次请求 Stash 扫描、生成和识别，并跟踪各步骤的后台任务。界面显示当前正在扫描、生成还是识别。生成步骤按目标 Scene ID 生成截图封面、预览、导航图片和 pHash，先准备指纹再进行识别。完整视频转码默认关闭，可在 **设置 → 入库 → 生成视频转码** 开启，开启后由 Stash 按需生成。
6. **已完成**：上述任务成功后，Moji 只读检查目标 Scene 的媒体文件，以及番号、标题、日期、片商和演员信息。缺失或番号不匹配时保留为受阻，避免把尚未整理好的影片显示为成品。

请先在 **Stash > 设置 > 任务 > Identify** 配置并保存识别来源及字段策略。Moji 使用 Stash 保存的来源顺序、全局选项和来源专属选项，不调用 `sceneUpdate` 写入元数据。未配置来源、未匹配或匹配不完整时，请在 Stash 修正配置或整理识别结果，再从 Moji 重试。生成和识别只处理当前任务收录的 Scene，不对整个库运行。

每个阶段还可能是待处理、进行中、受阻或已完成。“受阻”会保留可操作错误。重试从受阻的步骤继续，不会重新下载已经完成的内容，也不会重复已成功的搬运、扫描或生成。


当 Stash 中的影片记录被删除或重建时，Moji 会在生成、识别和最终验证前按交付路径核对 Scene ID。记录发生变化时，更新引用并从生成阶段继续，不重复下载或搬运。每轮最多自动恢复一次，恢复计数在重启后保留；记录持续变化或路径下没有影片时会显示具体受阻原因。人工重试会开启新一轮恢复。

## 管理任务

搜索范围包括番号、标题、tracker、阶段、种子标识和路径。可筛选运行中、完成、受阻或待扫描，再按创建时间、更新时间或进度排序。**刷新** 重新读取存储状态；**同步进度** 向 qBittorrent 获取当前状态；**触发扫描** 处理符合条件的已完成下载；**重试受阻任务** 批量重试所有受阻项。

自动选种没有可接受结果时，打开 **人工处理** 搜索并指定候选。提交前必须确认候选属于目标番号。删除任务可能同时删除 qBittorrent 任务和文件，具体取决于系统策略；确认窗口会显示当前效果。

## 文件整理与交付

文件分为四类：正片及其分段、字幕、明确的广告/样片/宣传文本/截图，以及用途无法确定的视频。明确冗余文件跳过下载和交付；字幕是否下载和交付由 **设置 > 入库 > 保留字幕** 控制，不判断语言。关闭时跳过外置字幕。单文件原样搬运，内嵌字幕始终保留；多分段合并时，内嵌字幕也按此设置处理。

Moji 以任务番号匹配文件，忽略广告域名前缀，并识别大小写、分隔符和补零变体。原始下载文件不改名。分段支持 A/B 和 -1/-2 等形式，按顺序合并。多个正片顺序不明确、存在缺口或包含未知视频时暂停下载；打开任务详情，在文件整理中选择正片并调整合并顺序，然后确认继续。

请使用 **文件交付**，配置 qB 下载根目录、Moji 下载根目录、Moji 媒体库根目录及 Stash 媒体库根目录。Moji 运行环境需要 `ffmpeg` 和 `ffprobe`。交付动作选择复制或移动。

复制保留下载源文件；移动在整部影片及字幕发布成功后才删除选中的下载源文件，qBittorrent 会先停止该任务，避免重新下载。两种方式均对单文件保留原格式，多分段合并为 MKV，不会把广告和其他冗余文件带入媒体库。

整理先核对文件清单和大小，按 SHA-256 去除完全相同的视频，若只剩单个正片则原样复制并核对哈希，不调用 FFmpeg 或 ffprobe；多分段才通过 ffprobe 检查兼容性、用 FFmpeg 无损合并并核对输出时长。分段参数不兼容时保留受阻状态，不自动降低画质转码。分段文本字幕按前序视频时长偏移后合并为 SRT，样式可能简化；无法可靠偏移的分段图形字幕会使任务受阻，可关闭字幕保留后重试。

合并在后台执行，不受网页请求超时影响。只有整理完成后才通知 Stash 扫描最终影片目录。任务会保存文件选择和顺序；已发布输出通过任务专属回执及内容哈希核验后可在重试中复用，不覆盖其他任务或用户已有的影片。完成条件沿用 Stash 扫描、生成、识别和现有结果检查。

## 重新选种

如果选错种子或人工确认时选错文件，可在任务详情的 **操作 > 重新选种** 从头执行。确认后会删除旧 qBittorrent 任务及其下载文件、已交付目录和交付凭据、对应 Stash 场景及生成资源，直接清除文件，不创建备份。此操作独立于系统的任务删除策略，即使系统设置为仅删除任务记录，也会清除上述文件。删除操作无法撤销。

保留原 Moji 任务条目和番号，清空旧种子、文件选择、下载进度、完成时间和入库引用。只有全部清理成功后才返回人工选种界面，随后重新执行文件选择、下载和完整入库流程。

仅支持尚未完成且没有正在运行的媒体搬运或 Stash 处理任务。无法验证文件归属、交付文件已被修改或场景关联了其他目录的文件时，会停止清理并显示受阻原因。清理中断后，再次执行同一操作或重试即可继续清除剩余产物；清理完成前不会进入新的下载，也不会自动选择上次的种子。
